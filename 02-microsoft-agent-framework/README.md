# Microsoft Agent Framework (MAF)

Welcome to the Microsoft Agent Framework lesson!

## What You'll Learn

This lesson introduces you to the Microsoft Agent Framework (MAF), a modern framework for building production-ready AI agents with Azure AI Foundry.

- How to create agents using the Microsoft Agent Framework
- How to retrieve and interact with existing agents
- Best practices for agent development with MAF

## What is Microsoft Agent Framework?

The Microsoft Agent Framework is a new framework from Microsoft designed to simplify building, deploying, and managing AI agents. It provides:

- **Simplified Development**: Easy-to-use APIs for creating intelligent agents
- **Azure Integration**: Seamless integration with Azure AI Foundry services
- **Production Ready**: Built-in features for monitoring, security, and scalability
- **Multi-Platform Support**: Available in both Python and .NET

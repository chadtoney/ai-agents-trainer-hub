# Introduction to AI Agents

Welcome to Module 1 of the AI Agents for Beginners course!

## What You'll Learn

This module provides comprehensive foundational knowledge across three key areas:

### 1. Introduction to AI Agents
- What are AI Agents and what are the different types of agents?
- What use cases are best suited for AI Agents?
- How AI agents differ from traditional AI solutions

### 2. Microsoft Foundry Agent Service
- Building agents with Azure AI Foundry
- Leveraging cloud-based agent orchestration
- Production-ready agent deployment

### 3. Agentic Design Patterns
- Core design patterns for building effective agents
- Best practices for agent architecture
- Patterns for tool use, planning, and multi-agent systems

## Learning Goals

After completing this module, you will be able to:

- Understand the concepts of AI Agents and how they differ from other AI solutions
- Build and deploy agents using Microsoft Foundry Agent Service
- Apply agentic design patterns to create robust agent solutions
- Design Agentic solutions efficiently for both users and customers

## Contents

This directory contains:

- **foundry_sample/**: Hands-on workshop materials covering all three module topics
  - `01-foundry-agent-workshop.ipynb`: Interactive notebook demonstrating:
    - Agent fundamentals and concepts
    - Building agents with Microsoft Foundry Agent Service
    - Implementing agentic design patterns
  - `data/`: Sample data for workshop exercises

## Getting Started

1. Ensure you have completed the [Course Setup](../00-course-setup/README.md)
2. Set up your Azure AI Foundry project and environment variables
3. Open the `foundry_sample/01-foundry-agent-workshop.ipynb` notebook
4. Follow along with the workshop exercises to learn agent fundamentals and build your first agents

Congratulations on starting your journey into AI agents! This foundational module has equipped you with essential knowledge across three critical areas:
